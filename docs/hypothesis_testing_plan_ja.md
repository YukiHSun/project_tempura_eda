# 仮説検定計画書（日本語版）

> **対象:** 原核生物 8,639 株（TEMPURA データセット）に対して、EDA で観察された
> 差や関連性が**統計的に有意**であるかを検証する。
> **位置づけ:** EDA（Phase 1）と回帰モデル（Phase 1.5）の次のステップとして、
> 「観察された差は偶然か、それとも真に存在するか」を仮説検定で裏付ける。
> **作成日:** 2026-05-06
> **作成者:** データプロフェッショナル（TEMPURA プロジェクト）

---

## 0. なぜ仮説検定フェーズを行うのか

EDA と回帰モデルから、次の**観察**は得られている:

- Archaea の `Topt_ave` 中央値 40 ℃ に対し、Bacteria は 30 ℃。
- 超好熱株 125 株のうち 92 % が Archaea。
- `16S_GC` と `Topt_ave` に中程度の正の相関（r ≈ 0.52）。
- 回帰モデルは R² = 0.918 で `Topt_ave` を予測できる。

しかしこれらは**記述**であって、次の問いに答えていない:

> 「Archaea と Bacteria の平均温度差は、**偶然では説明できない**レベルか？」
> 「超好熱における Archaea 集中は、たまたま観測されただけではないか？」

このギャップを埋めるのが、本 Phase の目的である。

---

## 1. 目的・成功基準（Ask）

### 1.1 目的

EDA で浮かび上がった3つの観察パターンについて、**帰無仮説検定**を実施し、
p 値と効果量を報告する。

### 1.2 成功基準

| # | 仮説 | 採用する検定 | 成果の形 |
|---|---|---|---|
| H1 | Archaea と Bacteria で `Topt_ave` の平均が等しい（H₀） | 二標本 Welch t 検定 | 検定統計量 / p 値 / 95% CI / Cohen's d |
| H2 | 超好熱株における Archaea の比率は、全体の Archaea 比率（6.35 %）と等しい（H₀） | 一標本 z 検定（比率） | z 値 / p 値 / 95% CI |
| H3 | `temp_cat` と `superkingdom` は独立（H₀） | カイ二乗独立性検定 | χ² / p 値 / Cramér's V |
| H4 | 4 温度カテゴリ間で `16S_GC` の平均は等しい（H₀） | 一元配置 ANOVA | F / p 値 / η² |

- **有意水準 α = 0.05**（通常の基準。Bonferroni 補正は §5.3 を参照）。
- **効果量**を必ず併記する（p 値は「有意性」しか語らない）。

---

## 2. 想定外・スコープ外

- 因果推論は行わない（観察データなので相関までしか論じない）。
- 多重比較に関する完全な family-wise error 制御は行わず、Bonferroni で簡易補正する。
- ベイズ的検定（BF など）は扱わない。

---

## 3. データ（Prepare）

- `data/raw/tempura.csv` — 8,639 行 × 20 列（EDA と共通）。
- 派生列 `temp_cat`（好冷 / 中温 / 好熱 / 超好熱）は EDA と同じ閾値で再生成する。

### 3.1 前提の点検（各検定ごと）

| 検定 | 点検する前提 | 手段 |
|---|---|---|
| t 検定 | 近似的に正規（大標本なので CLT で担保）／分散未知・不等 | Welch 補正で不等分散許容／QQ プロットで目視 |
| z 検定（比率） | 正規近似の条件 `n·p ≥ 10` と `n·(1−p) ≥ 10` | 実データで満たされるか確認 |
| カイ二乗 | 各セル期待度数 ≥ 5 | クロス集計で期待度数計算 |
| ANOVA | 各群の分散がほぼ等しい（Levene 検定）／独立・正規近似 | Levene + 各群 QQ プロット |

## 4. 仮説と検定の詳細（Construct）

### H1. Archaea と Bacteria で `Topt_ave` 平均は異なるか

- **H₀:** μ_Bacteria = μ_Archaea
- **H₁:** μ_Bacteria ≠ μ_Archaea（両側）
- **検定:** 二標本 **Welch の t 検定**（分散不等・n 不等に頑健）
  - `scipy.stats.ttest_ind(bact, arch, equal_var=False)`
- **効果量:** Cohen's d（pooled SD は不等分散なので √((s1²+s2²)/2) で代替）
- **補助出力:** 各群の平均・標準偏差・95 % CI、差の 95 % CI

### H2. 超好熱カテゴリにおける Archaea 比率は全体比率と等しいか

- **全体の Archaea 比率:** 549 / 8,639 ≈ 0.0635（ベースライン）
- **H₀:** p（超好熱株の Archaea 比率）= 0.0635
- **H₁:** p > 0.0635（片側。EDA で上振れが観察されたため）
- **検定:** 一標本 **z 検定（比率）**
  - 手計算: z = (p̂ − p₀) / √(p₀(1−p₀)/n)
  - あるいは `statsmodels.stats.proportion.proportions_ztest(count, nobs, value)`
- **副産物:** 95 % Wilson CI

### H3. `temp_cat` × `superkingdom` の独立性

- **H₀:** temp_cat と superkingdom は独立
- **H₁:** 独立ではない
- **検定:** **カイ二乗独立性検定**（4×2 分割表）
  - `scipy.stats.chi2_contingency`
- **効果量:** **Cramér's V** = √(χ² / (n · min(r−1, c−1)))
- **注意:** 期待度数 < 5 のセルが多いと近似が崩れるため確認する。

### H4. 4 温度カテゴリ間で 16S_GC 平均は等しいか

- **H₀:** μ₁ = μ₂ = μ₃ = μ₄（4 カテゴリで平均 16S_GC が同じ）
- **H₁:** 少なくとも 1 ペアで異なる
- **検定:** **一元配置 ANOVA**
  - `scipy.stats.f_oneway`
- **ポストホック:** Tukey HSD で**どのペアに差があるか**を明らかにする
  - `statsmodels.stats.multicomp.pairwise_tukeyhsd`
- **効果量:** η² = SS_between / SS_total

## 5. 検証プロトコル（Analyze）

### 5.1 実行環境
- Python 3.12 / `scipy` / `statsmodels`
- `random_state = 42` を必要に応じて固定

### 5.2 指標一覧

| 指標 | 役割 |
|---|---|
| 検定統計量（t / z / χ² / F） | 検定の中心値 |
| p 値 | 帰無仮説棄却の根拠 |
| 95 % CI | 効果の方向・大きさを伴う推論 |
| 効果量（Cohen's d / Cramér's V / η²） | 有意性とは独立に「差の実質的大きさ」を評価 |

### 5.3 多重比較補正

4 つの仮説を同時に検定するため、**Bonferroni 補正**を参考値として併記する:
- 補正後 α = 0.05 / 4 = **0.0125**
- 各仮説の p 値が 0.0125 未満かも確認する

---

## 6. 公平性・ガバナンス

- Archaea（n = 549, 6.35 %）は**過小代表**の属性。
  - H1 では Welch t 検定を使うことで、分散・サンプルサイズの非対称を許容する。
  - H3 / H4 では期待度数・各群 n を**必ず表示**し、結論の頑健性を確認する。
- 片側検定を使う場合（H2）は、EDA の観察に基づく事前予測であることを明記する。
  - 後付け片側検定（HARKing）に陥らないよう、計画段階で方向を決める。

## 10. 実行後の判断ポイント

- **全仮説で p < 0.0125（Bonferroni 補正後）かつ効果量中程度以上:**
  → EDA の観察が統計的にも強く支持される。研究方針への信頼性が上がる。
- **一部仮説で p > 0.05:**
  → その仮説は「データ上は偶然で説明しうる」。モデルに組み込む根拠としては弱い。
- **p < 0.05 だが効果量が小さい:**
  → 「統計的には有意だが実質的にはごく僅か」。研究優先度の判断材料にしない。
