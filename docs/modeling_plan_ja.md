# `Topt_ave` 予測モデル計画書（日本語版）

> **対象:** 原核生物 8,639 株の最適生育温度 `Topt_ave` を予測する回帰モデル
> **位置づけ:** `executive_summary_ja.md` §3.1「Ridge / PLS 回帰」を実装可能な単位まで詳細化したもの
> **作成日:** 2026-05-06
> **作成者:** データプロフェッショナル（TEMPURA EDA プロジェクト）

---

## 0. なぜこのモデルを作るのか（再確認）

EDA で分かったこと:

- `Topt_ave` は 2〜106 ℃ に分布、中央値 30 ℃、σ ≈ 11.6 ℃。
- `Tmin` / `Tmax` と強く相関（r = 0.84 / 0.93）。
- `16S_GC` とも中程度の正の相関（r ≈ 0.52）。
- **超好熱 125 株のうち 92 % が Archaea**。分類グループと温度に強い関係がある。

→ **Ridge 回帰**で十分に高い性能が期待できる一方、多重共線性と
クラス不均衡（Bacteria : Archaea = 93 : 6）の扱いが設計の中心課題となる。

---

## 1. 目的・成功基準（Ask）

### 1.1 事業目的

- 新規株（未 EDA の株）の `Tmin`・`Tmax` ・ `16S_GC` ・分類情報から、
  `Topt_ave` を予測できるモデルを 1 本用意する。
- 研究マネージャーが**スクリーニングの初期仮説**を立てる段階で使用する想定。

### 1.2 数値目標

| 指標 | 目標値（全体） | 目標値（Archaea サブグループ） |
|---|---|---|
| **MAE**（平均絶対誤差, ℃） | ≤ 4.0 | ≤ 6.0 |
| **RMSE** | ≤ 6.0 | ≤ 10.0 |
| **R²** | ≥ 0.85 | ≥ 0.70 |
| **MAE (Bacteria)** | ≤ 3.5 | — |

> Archaea は分布が広いため、目標値を**緩める**。Bacteria に最適化したモデルが
> Archaea で大きく外す事故を避ける。

---

## 2. 想定外・スコープ外

- 時系列予測ではない（温度そのものが目的変数、時間は無関係）。
- 系統分類からのゼロショット一般化（未見の `phylum` への適用）は
  評価対象外とする。
- モデル本番化 (MLOps) は後続コースに委ねる。

---

## 3. データ（Prepare）

### 3.1 入力データ

- `data/raw/tempura.csv` — 8,639 行 × 20 列（EDA 済み）。

### 3.2 特徴量設計

| 特徴量 | 型 | 備考 |
|---|---|---|
| `Tmin` | 数値 | 温度端点、100 % 埋まっている |
| `Tmax` | 数値 | 温度端点、100 % 埋まっている |
| `Tmax_Tmin` | 数値 | 既存の派生指標（`Tmax − Tmin`） |
| `16S_GC` | 数値 | 16S rRNA GC 含量。欠損 < 0.2 % |
| `Genome_GC` | 数値 | ゲノム GC 含量。欠損 4.5 %。中央値で補完 |
| `superkingdom_Archaea` | 二値ダミー | Bacteria = 0 / Archaea = 1 |
| `phylum_*` | One-Hot | 出現率 ≥ 1 % の門のみ残し、残りは `phylum_other` に集約 |

### 3.3 外れ値・リーケージ対策

- **リーケージ:** 分類情報と `Topt_ave` は無関係に独立取得されているため
  分類カラムをそのまま特徴量として使って問題ない。
- **外れ値:** 超好熱株（≥ 80 ℃）は実在する生物シグナルであり、**削除しない**。
- **欠損処理:**
  - 数値: `SimpleImputer(strategy='median')`
  - `phylum` カテゴリ: `SimpleImputer(strategy='constant', fill_value='Unknown')`

### 3.4 スケーリング

- Ridge は係数に正則化を効かせるため、数値特徴量は
  `StandardScaler` で標準化する。
- 勾配ブースティングはスケール不変なため、スケーリング不要。

---

## 4. モデル候補（Construct）

### 4.1 ベースライン

- **Dummy regressor**（平均値予測）: 「何もしないモデル」の性能。
  これを下回るモデルは棄却。

### 4.2 本命モデル 1 — Ridge 回帰

- 多重共線性（`Tmin`・`Tmax` 間 r = 0.79）に対して正則化が効く。
- 解釈性が高く、研究マネージャーが係数の意味を読める。
- ハイパーパラメータ: `alpha` を `{0.1, 1.0, 10.0, 100.0}` で探索。

### 4.3 本命モデル 2 — 勾配ブースティング（HistGradientBoosting）

- 非線形性（特に Archaea の広い分布）に強い。
- 実用上の精度のベンチマーク。
- ハイパーパラメータ: `max_depth ∈ {3, 5, 7}`、`learning_rate ∈ {0.05, 0.1}`。

### 4.4 モデル選定ルール

1. CV スコアの **MAE（全体）** が最良のものを選ぶ。
2. ただし **Archaea サブグループでの MAE** が §1.2 の目標を
   上回るなら、たとえ全体 MAE が劣っても**そちらを優先**する。

---

## 5. 検証プロトコル（Analyze）

### 5.1 分割戦略

- **5-fold クロスバリデーション**。
- **`superkingdom` で層化**（`StratifiedKFold`）。
  → Archaea が約 110 株ずつ、全 fold に確実に含まれる。
- ランダムシード `random_state=42` を固定。

### 5.2 評価指標

| 指標 | 役割 |
|---|---|
| MAE | 主指標（解釈性が高い） |
| RMSE | 大きな外し（超好熱の予測ミス）を重視 |
| R² | 相対的な説明力 |

### 5.3 サブグループ評価

- **superkingdom 別** (Bacteria / Archaea) で MAE / RMSE を必ず算出する。
- **温度カテゴリ別** (psychro / meso / thermo / hyperthermo) でも MAE を算出し、
  `temp_cat` の偏りを監査する。

### 5.4 可視化（必須）

- 予測値 vs 実測値の散布図（全体・superkingdom 別）。
- 残差のヒストグラム。
- Ridge の係数重要度（標準化後）上位 10 本。

## 9. リスクと緩和

| リスク | 影響 | 緩和策 |
|---|---|---|
| Archaea の CV fold ごとの株数揺れ | 中 | 層化 KFold を使う・fold ごとの指標も個別表示 |
| 多重共線性で Ridge の係数が不安定 | 中 | alpha を大きめ寄りに探索、特徴量の相関も報告 |
| GBDT の過学習 | 中 | `max_depth ≤ 7`、early stopping 相当の `max_iter` 制御 |
| 2020 年版の分類体系で訓練 → 新名称で失敗 | 低 | 本番化時にリスクとして文書化（今回はスコープ外） |
