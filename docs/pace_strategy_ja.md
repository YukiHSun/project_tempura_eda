## 0. プロジェクトの位置づけ

あるバイオテック企業の研究マネージャーが、極限環境性の原核生物に関する
研究プログラムのスコープを検討している。高コストな湿式実験に進む前に、
公開データベース上のカタログ株群における**生育温度のランドスケープ**を
データ駆動で把握し、**後段で予測モデルを構築する価値があるか**を
判断したい、というのが発注者側の要望である。

PACE フレームワーク（**Plan → Analyze → Construct → Execute**）は、
この依頼をデータプロフェッショナルが**一気通貫で解く**ための骨格を提供する。

## 2. Analyze（分析）

### 2.1 構造の点検

pandas の 3 つの定番呼び出しを、目的を分けて使う。

| 呼び出し | 目的 | 得られたこと |
|---|---|---|
| `df.head()` | 生データの妥当性確認 | 分類カラム＋温度カラムが揃い、冒頭に 122 ℃ などの極値が現れる（エラーではなく実在の極限株） |
| `df.info()` | 型と欠損の把握 | 温度の主軸指標は 100 % 埋まるが、`Topt_low/high` は約 64 %、`Genome_size` は約 88 % が欠損 |
| `df.describe()` | 要約統計 | `Topt_ave` 中央値 30 ℃、レンジ 2–106 ℃。`Tmin` −20〜+90 ℃、`Tmax` 最大 122 ℃ |

### 2.2 洗い出した品質リスク

- **深刻な欠損** — ゲノム関連メタデータ（`assembly_or_accession`・`Genome_size`）は
  オプショナル特徴量としてのみ利用可。
- **クラス不均衡** — Archaea (n = 549) と Bacteria (n = 8,090)。
  モデルでは明示的に扱う必要がある。
- **裾の長い数値分布** — 回帰では変換や**ロバストな推定量**を検討すべき。

### 2.3 この段階で回答できた問い

- **Q-D 解決済み。** 4 つの主要温度カラムのデータ品質は良好。
  ゲノム系・レンジ系カラムの品質は低く、利用を限定する。

## 3. Construct（構築）

### 3.1 可視化（各問いに対応）

| 図 | 対応する問い | 主な気づき |
|---|---|---|
| `Topt_ave` のヒストグラム | Q-A | 右に歪んだ分布。88 % が中温、長い超好熱の裾 |
| `superkingdom` 別の箱ひげ図 | Q-B | Archaea の IQR は Bacteria の 5 倍広く、≥ 80 ℃ 帯を支配 |
| 温度カテゴリのクロス集計 | Q-B | 超好熱 125 株中 **115 株（92 %）が Archaea** |
| 相関ヒートマップ | Q-C | `Topt_ave`↔`Tmax` r=0.93、`Topt_ave`↔`Tmin` r=0.84、GC は弱相関 |

### 3.2 派生特徴量

- `temp_cat`（カテゴリカル）— 好冷 / 中温 / 好熱 / 超好熱。
  下流で再利用できる**報告用のバケット**。

### 3.3 再現性

- Notebook は生 CSV から**エンドツーエンドで再実行**できる。
- サンプリング・モデリングを行わないため乱数シード不要。
- 依存ライブラリのバージョンは `requirements.txt` で固定。

## 4. Execute（実行）

### 4.1 研究マネージャーに伝える発見

1. データは**中温性 Bacteria（Topt 27.5–33.5 ℃、IQR 6 ℃）**が支配している。
2. 極限環境研究のターゲットは **Archaea**。IQR は Bacteria の 5 倍広い
   （37.0–67.5 ℃）。
3. 温度指標どうしの情報は大きく重なる（r ≥ 0.79）。
   回帰の**目的変数は `Topt_ave` の 1 本**でよい。
4. データ品質は**予測モデル構築に耐える水準**にある。

### 4.2 推奨される次ステップ

- **Ridge / PLS 回帰** — `Topt_ave` を、`Tmin`・`Tmax`・
  `Genome_GC`・`16S_GC` と分類ダミー変数から予測。
- **4 クラス分類** — `temp_cat` バケットを目的変数にし、
  **クラス重み付き評価指標（macro-F1）** を用いる
  （93:6 の不均衡のため）。
- **層化評価** — 評価時は必ず **`superkingdom` で層化**。
  Bacteria に引っ張られた accuracy で Archaea での低性能を
  覆い隠さない。

### 4.3 伝達チャネル

- **Notebook**（`notebooks/tempura_eda.ipynb`）— 技術者向け。
- **エグゼクティブサマリー**（`docs/executive_summary.md` / `_ja.md`）— 研究マネージャー向け。
- **この戦略文書** — バイオインフォリードと倫理担当向け。

## 5. 倫理と公平性

- **ライセンス遵守。** データは TogoDB の学術ライセンスで取得。
  生 CSV は本リポジトリに**再配布しない**。取得手順は
  `data/README.md` に明記。
- **代表性バイアス。** Archaea は約 6 %。無作為分割では
  一部 fold に Archaea がほぼ含まれない恐れがある。対策は
  **層化分割**と**サブグループ別指標**の併用。
- **データのヴィンテージ。** ファイルは **2020-06-17** の
  スナップショット。分類体系はその後変化している
  （例: NCBI Taxonomy のリネーム）。すべての発見には
  「2020 年時点」の注記を付ける。
- **引用。** 後続の発表では必ず Sato Y, Okano K, Kimura H,
  Honda K (2020) *Microbes and Environments* 35:ME20074 を引用する。
