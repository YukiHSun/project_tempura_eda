# エグゼクティブサマリー — TEMPURA EDA

> **プロジェクト:** 原核生物 生育温度の探索的データ分析 (EDA)
> **データセット:** TogoDB / TEMPURA（8,639 株、2020 年版）
> **対象読者:** 極限環境微生物プログラムのスコープを検討する研究マネージャー
> **作成日:** 2026-05-06
> **ルーブリック対応:** Q7（実施タスク）・Q8（データの可変性評価）・Q9（次ステップ）

---

## 1. 本プロジェクトで実施したタスク（Q7）

1. **データ取得。** TogoDB の学術ライセンスに同意した上で TEMPURA データベースをダウンロード
   （ファイル日付 2020-06-17、8,639 行 × 20 列）。
2. **構造レビュー。** CSV を pandas に読み込み、`head()` / `info()` / `describe()` で
   スキーマ・型・欠損パターン・数値レンジを把握。
3. **品質評価。** 全列の欠損率を算出し、分析で信頼できる列を特定。
4. **可変性の評価。** `Tmin`・`Topt_ave`・`Tmax` の分布と相関を、
   全体と **superkingdom**（Bacteria / Archaea）別の両方で要約。
5. **カテゴリ特徴量の作成。** `temp_cat`（好冷・中温・好熱・超好熱）を導出し、
   `superkingdom` とのクロス集計を作成。
6. **可視化。** 主要な3つの発見を伝えるため、ヒストグラム・箱ひげ図・相関ヒートマップを作成。
7. **ドキュメンテーション。** PACE 戦略文書、このエグゼクティブサマリー、
   リポジトリ README を記述し、分析が再現可能な状態を整備。

## 2. データの可変性 — 何が見えたか（Q8）

### 2.1 主要統計量

| 指標 | `Tmin` | `Topt_ave` | `Tmax` |
|---|---|---|---|
| n（非欠損） | 8,639 | 8,639 | 8,639 |
| 平均（℃） | 15.79 | 33.07 | 41.87 |
| 標準偏差（℃） | 12.05 | **11.56** | 12.01 |
| 最小 / 最大（℃） | −20 / 90 | 2 / 106 | 10 / 122 |
| 中央値（℃） | 15 | 30 | 40 |
| IQR（℃） | 10 | 8 | 8 |

**読み取り:** 3 つの温度指標はいずれも標準偏差 σ ≈ 12 ℃ と似た広がりを持つが、
中心は異なる。IQR はどれも狭く（≤ 10 ℃）、「典型的な」株は中温性。
しかし**上側の長い裾**に、生物学的に興味深い変動がすべて含まれている。

### 2.2 superkingdom 間の非対称性

| Superkingdom | n | `Topt_ave` 中央値 | `Topt_ave` IQR | `Topt_ave` 最大 |
|---|---|---|---|---|
| **Bacteria** | 8,090（93.6 %） | 30 ℃ | 27.5–33.5（6 ℃） | 85 ℃ |
| **Archaea**  | 549（6.4 %）   | 40 ℃ | 37.0–67.5（30.5 ℃） | 106 ℃ |

**読み取り:** Archaea は Bacteria より**約 5 倍広い**温度分布を持ち、
中央値もはるかに高温側にある。これがデータセット最大の構造的特徴であり、
モデリングの設計にも直接影響する（§3 参照）。

### 2.3 温度カテゴリ別の内訳

| カテゴリ（Topt ℃） | Bacteria | Archaea | 合計 |
|---|---|---|---|
| 好冷（Psychrophile, < 20）       |   203 |     3 |   206 |
| 中温（Mesophile, 20–45）         | 7,249 |   327 | 7,576 |
| 好熱（Thermophile, 45–80）       |   628 |   104 |   732 |
| **超好熱（Hyperthermophile, ≥ 80）** | **10** | **115** | **125** |

**読み取り:** カタログ上の超好熱株 125 株のうち、**115 株（92 %）が Archaea**。
既知の生物学と一致する鮮烈な集中パターンであり、
極限環境微生物研究のターゲット集団は **Archaea** であることを示唆する。

### 2.4 温度指標間の関係

| ペア | Pearson r |
|---|---|
| `Tmin` ↔ `Topt_ave` | 0.844 |
| `Topt_ave` ↔ `Tmax` | 0.930 |
| `Tmin` ↔ `Tmax`    | 0.790 |
| `Topt_ave` ↔ `Genome_GC` | −0.114 |
| `Topt_ave` ↔ `16S_GC`    | +0.519 |

**読み取り:** 3 つの温度指標はほぼ**多重共線的**で、すべてを独立な特徴量として
回帰に投入すべきではない。GC 含量の寄与は限定的で、
ゲノム全体の GC より **16S rRNA の GC 含量**（r ≈ 0.52）のほうが情報量が大きい。

### 2.5 データ品質上の注意点

- `Topt_low`・`Topt_high` は **約 64 % が欠損** → そのまま使わない方が安全。
- `Genome_size`・`assembly_or_accession` は **約 88 % が欠損** →
  オプショナルな特徴量として扱う。
- 主軸の 4 つの温度指標（`Tmin`・`Topt_ave`・`Tmax`・`Tmax_Tmin`）は
  **100 % 埋まっている** → 本分析はこれらを土台としている。

## 3. 推奨される次ステップ — 予測モデルへ（Q9）

上記の可変性評価から、次の進め方が明確に導ける。

### 3.1 回帰モデル — `Topt_ave` を予測

- **目的変数:** `Topt_ave`（連続値、℃）
- **特徴量:** `Tmin`・`Tmax`・`16S_GC`・`Genome_GC`・superkingdom/phylum のダミー変数
- **モデル:** **Ridge** または **PLS 回帰**。温度指標が強く相関（r ≥ 0.79）しているため、
  普通の OLS では過学習・係数の不安定化が起きる。
- **検証:** 5-fold CV、**`superkingdom` で層化**することで、
  各 fold に Archaea が確実に含まれるようにする。

### 3.2 分類モデル — `temp_cat` を予測

- **目的変数:** 4 クラスラベル（好冷 / 中温 / 好熱 / 超好熱）
- **なぜ 2 つめのモデルか:** このラベルは研究マネージャーにとって
  **アクション可能**（サンプリング戦略や培地選択に直結）だから。
- **クラス不均衡:** 2.4 % / 87.7 % / 8.5 % / 1.4 %。
  クラス重み付け or focal loss を使い、**macro-F1** で評価する
  （accuracy だけでは多数クラスに引きずられる）。

### 3.3 データ拡充

- `taxonomy_id` をキーに **NCBI Taxonomy** に結合し、
  生育環境・分離源などのメタデータを取得する。
- 海洋分離株については、海洋学的・地理的文脈を付与できる可能性がある。

### 3.4 公平性とモデル・ガバナンス

- Bacteria : Archaea = 93 : 6 の偏りは**代表性バイアス**のリスク。
  すべての評価指標は **superkingdom 別に**分けて報告し、
  Bacteria 主導の accuracy が **Archaea での性能不足を隠さない**ようにする。
- 本番モデルには「**2020 年版**」の注記を必ず付ける。
  それ以降、分類体系（例: NCBI Taxonomy）は変化しており、
  2020 年以降に登録された株への予測は要注意。

> TEMPURA には 8,639 株が収録され、温度指標はすべて 100 % 埋まっている。
